# 真实数据库对接进展

日期：2026-09-09

## 当前进展

1. 已关闭主要业务入口的本地假数据兜底。
   - 登录不再写入 `mock-access-token`。
   - `VITE_USE_MOCK=false` 时，`withMock` 不再在接口失败后返回本地 mock 数据。
   - 教师端首页、作文列表、错题列表、错题详情、分层记录、分层组卷、教师目录等页面已改为请求接口数据。

2. 已新增真实数据库连接层。
   - 新增 `backend/db.mjs`，支持 `DATABASE_URL` / `MYSQL_URL`。
   - 也支持 `DB_HOST`、`DB_PORT`、`DB_NAME`、`DB_USER`、`DB_PASSWORD` 分项配置。
   - 未配置数据库时，接口返回明确的 503 错误，不再返回演示数据。

3. 已重构本地 API 入口。
   - `api/_app-api.js` 支持两种真实数据模式：
     - `APP_API_PROXY_TARGET`：透明转发到已有业务后端。
     - 直连 MySQL：按当前仓库已有 SQL 设计读取真实表。
   - 已接入或补齐的读取接口包括登录、公钥、权限信息、教师信息、教师分页、教师首页统计、学生概览、题库统计、近期作业、近期组卷、作文分页、错题统计、错题详情、分层策略等。
   - 重置密码、权限同步、下载、继续组卷等未确定真实后端行为的写入/动作类接口，不再本地伪造成功，改为明确提示需要转发到业务后端。

4. 已清理会误导后续开发的演示说明。
   - `src/config/README.md` 已改为真实数据接入说明。
   - `src/pages/system/Permissions.vue` 已移除注释中的 Mock 权限页实现。
   - `src/main.ts` 已移除注释中的 Mock 服务初始化残留。
   - 忘记密码页改为调用真实接口，不再提示“演示发送成功”。

5. 已安装 MySQL 驱动。
   - `package.json` / `package-lock.json` 新增 `mysql2`。

## 验证结果

已执行并通过：

```bash
npm run type-check
npm run build
node -e "import('./api/_app-api.js').then(() => console.log('api import ok'))"
```

本地 API 在没有数据库配置时返回：

```json
{
  "code": 503,
  "msg": "未配置真实数据库，已停止返回演示假数据。请设置 DATABASE_URL 或 DB_HOST/DB_NAME/DB_USER/DB_PASSWORD。"
}
```

这说明当前状态下系统不会继续用演示假数据欺骗页面，而是暴露真实数据库尚未配置的问题。

## 当前限制

1. 还没有真实数据库连接信息，无法验证真实库查询结果。
2. 仓库只有部分业务表 SQL 设计，缺少完整生产库 schema。
3. 部分接口属于写入、上传、下载、生成、批改动作，不能在没有真实后端契约时随意直连模拟。
4. 当前更适合优先接入已有业务后端；如果必须直连 MySQL，需要提供真实表结构后逐个校准 SQL 字段。

## 下一步推进方向

1. 提供真实后端地址，配置：

```env
APP_API_PROXY_TARGET=https://your-api-host
VITE_USE_MOCK=false
```

这是最快完成全量真实数据对接的方式，所有 `/api/v1/*` 请求会直接转发到业务后端。

2. 如果没有业务后端，提供 MySQL 连接与 schema，配置：

```env
DATABASE_URL=mysql://user:password@host:3306/database
VITE_USE_MOCK=false
```

然后按页面优先级继续校准：

- 登录与用户权限
- 教师首页统计
- 作业/组卷列表
- 作业详情与批改数据
- 题库列表与题目详情
- 学生、班级、教师教务管理
- 学情报告和图表分析

3. 对剩余未接入的动作类接口建立真实后端契约。
   - 文件上传
   - 作业下载
   - 继续组卷
   - 人工批改提交
   - 密码重置
   - 权限同步

4. 完成真实库验证后，再删除或隔离 `src/config/mock/` 历史参考目录，避免后续误用。
